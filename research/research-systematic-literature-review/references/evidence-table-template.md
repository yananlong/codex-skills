## Extraction guidance

- Use one row per included study.
- Fill publication_url with the canonical published or accepted venue record whenever it exists: publisher page, proceedings page, DOI resolver, PubMed/PMC record, society digital-library page, or accepted venue forum.
- Prefer citing the peer-reviewed published version when available; use preprint links only as supplemental full-text access or as the canonical publication_url when no published/accepted version exists.
- Keep outcome labels consistent across rows.
- Capture numeric effect sizes where available.
- Mark uncertainty explicitly instead of inferring unsupported values.
